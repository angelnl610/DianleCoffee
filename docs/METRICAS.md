# Métricas y criterios

| Tipo | Definición |
| --- | --- |
| KPI principal | Reducción del tiempo humano semanal. Baseline hipotético 12 h. Meta tentativa 3 h (75%). |
| KPI calidad | Errores confirmados / ofertas revisadas. El 10% de ficha es comparable solo con metodología equivalente. |
| Métricas Analytics | Observaciones, productos distintos, marcas, comercios, cobertura, promoción conocida, mediana e IQR por segmento. |
| Índice competitivo | Precio unitario / mediana comparable. Indicador descriptivo, con mínimo de 8 ofertas. |
| Umbrales | Brecha ±10% como hipótesis configurable de revisión. Atípicos: fuera de Q1−1,5 IQR a Q3+1,5 IQR. |
| Métricas modelo | MAE en ARS para seleccionar por validación. RMSE enfatiza errores grandes. R² puede ser negativo si el error cuadrático supera la referencia implícita de la media del test. |

Medí tiempo de máquina, tiempo humano y muestra revisada por separado. El protocolo usa tres conjuntos agrupados por producto. El baseline es la mediana de train. Información mutua y Pearson describen dependencia y asociación del conjunto publicado. La versión supervisada registra señales de train.
